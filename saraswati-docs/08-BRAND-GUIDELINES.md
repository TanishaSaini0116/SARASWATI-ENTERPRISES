# BRAND-GUIDELINES.md — Saraswati Enterprises

## 1. Logo Usage
Received from client: `saraswati-logo-full.png` (full lockup — icon, name, service icons, taglines combined) and `saraswati-icon-transparent.png` (icon-only, transparent background, cropped for header/footer use). Both live in `/public/images/logo/`.

- Use **`saraswati-icon-transparent.png`** in the Header and Footer (small size, transparent — pairs with real HTML text for "Saraswati Enterprises," not baked-in text).
- Use **`saraswati-logo-full.png`** only on the About page and official documents (quotes, brochures, proposals) where the full lockup with taglines and service icons is appropriate.
- Minimum clear space around the logo: equal to the height of the icon mark on all sides.
- Never stretch, recolor, rotate, or place the logo on a low-contrast background.
- The icon crop currently has a soft-edged transparency (near-white pixels faded to transparent). If a cleaner hard-edged cutout is needed later, redo the crop with a proper background-removal tool (e.g. remove.bg) from the original source file.

## 2. Brand Colors
**Status: FINALIZED — LOCKED.** "Warm Trust" palette plus one muted green accent pulled from the logo itself, confirmed as a match against the real logo file. This is the signed-off brand record; `DESIGN.md` should always match this table exactly.

| Role | Hex | Notes |
|---|---|---|
| Primary | `#26495C` | Deep blue — headers, nav, buttons, footer |
| Accent | `#6C9BB0` | Soft blue — links, hover states |
| Green Accent | `#7A9B6E` | Muted version of the logo's green. Sparing use only — badges, tags, success states. Never a dominant color. |

## 3. Typography
- Headings: Space Grotesk or Sora
- Body: Inter or IBM Plex Sans
- Never introduce a third typeface without updating this file first.

## 4. Tone of Voice
- **Confident, not salesy.** We state facts and capability, we don't oversell.
- **Technical when it matters.** Industrial/pharma audiences respect precision (numbers, compliance terms) over marketing fluff.
- **Warm when addressing residential customers.** Simpler language, reassurance-focused, less jargon.
- Avoid: exclamation-heavy copy, vague superlatives ("best-in-class", "world's finest") without backing data.
- Always prefer specific claims ("15+ years, 500+ installations") over generic ones ("years of experience").

## 5. Imagery Style
- Real installation photos > stock photos, wherever available.
- If stock is unavoidable, prefer clean, well-lit, realistic industrial/water imagery — not overly staged corporate stock.
- Product photos should be well-lit, neutral background, consistent angle across the catalog for visual consistency.
